The release binary includes Go's standard library and the following third-party code. Their notices are included here.

- `GIRAFFESYO-PDF.txt`: PDF parsing and text extraction, Apache-2.0.
- `PDF-CJK-NOTICE.txt` and `PDF-STDFONT-NOTICE.txt`: data notices included by that PDF package.
- `GO-X-IMAGE.txt`: raster resizing and format support, BSD-3-Clause.
- `GO-X-SYS.txt` and `GO-X-TEXT.txt`: Go support libraries, BSD-3-Clause.
- `GO.txt`: Go standard library, BSD-3-Clause.
- `LICENSE-MIT.txt` in each archive covers this project's native source.
