Standalone native CLI for image and PDF inspection on Windows, Linux, and macOS. The npm 0.1.9 package bundles native binaries for Windows, Linux, and macOS on x64 and ARM64; its `agent-tools` command selects the matching binary for image and PDF commands.

Image preparation, cropping, PDF text extraction, and search do not require Node.js or Python. OCR commands need a local Tesseract 5 installation and English language data. See the included README for commands, supported formats, limits, and setup.
